## Who's That Pokemon?
Uses PokeAPI to keep regular updates

Automatic PokeAPI updates will not include aliases, qualifiers, or skipped pokemon. Aliases are alternate ways to write a pokemon's name, such as specifying a form or writing nidoran instead of nidoran-f. Qualifiers are used in specific mode to require form names to be specified. Skips are used to skip pokemon that are identical for the purposes of this game, yet are included in PokeAPI, such as Alolan Raticate and Totem Alolan Raticate.

Commands (Type the command then hit return/enter):
- Modes/Settings
    - POKERAP
        - Enter Pokerap mode, replaces random pokemon with the kanto pokerap
        - Disables Random Mode
    - SPECIFIC
        - Enables Specific Mode
        - Require specific qualifiers when guessing pokemon
        - for example: "Mega Venusaur" instead of just "Venusaur" for venusaur-mega
        - qualifiers must be set in pokemon_data.json, and thus will not update automatically
    - NOSPECIFIC
        - Disables specific mode
    - FASTMODE
        - Enables fast mode
        - Uses threading to reduce or even remove loading times between pokemon
        - Also removes the color pokemon appearing to reduce flashing
    - NOFAST
        - Disables fast mode
    - RANDOMIZE
        - Enables Random Mode
        - Pokemon order is randomized after finishing or applying a filter
        - On by default
    - NORANDOMIZE
        - Disabled Random Mode
        - When finishing or applying a filter, the order will stay the same
        - May be caused by other modes, such as POKERAP
    - NUMERICAL
        - Switch to Numerical Mode
        - Disables Random Mode
        - Orders pokemon by dex number
    - ALPHABETICAL
        - Switch to Alphabetical Mode
        - Disables Random Mode
        - Orders pokemon alphabetically by id
- Filters
    - ONLYSPECIFIC
        - Limit the pool of pokemon to only those affected by specific mode
    - INVERT
        - Switch the pokemon pool to all pokemon not in the current pool
    - CONTAINS:&lt;filter&gt;
        - Restricts the pool to only ids containing filter
        - Accepts | to include pokemon matches any given condition
    - START:&lt;letter&gt;
        - Restricts the pool to only ids starting with letter
    - TYPE:&lt;type&gt;
        - Restricts the pool to only pokemon of the given type
        - Accepts | to include pokemon of different types
        - Accepts & to include pokemon of multiple simultaneous types
        - Does not accept | and & at the same time
    - BEFORE:&lt;number&gt;
        - Restricts the pool to only pokemon whose dex number is less than or equal to number
    - AFTER:&lt;number&gt;
        - Restricts the pool to only pokemon whose dex number is greater than or equal to number
- Other
    - RESET
        - Resets the game to its original state
    - QUIT
        - Closes the game
    - REVERSE
        - Reverses the pokemon list.
        - Disables Random Mode
